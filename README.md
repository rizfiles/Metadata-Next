# Metadata-Next

A browser-based tool that generates **titles, keywords and categories** for your images and exports them as CSV files ready for **Adobe Stock** and **Shutterstock**.

It runs entirely in your browser. There is no backend: you bring your own **Gemini API Key**, and your images are sent directly from your browser to Google.

## Features

- Upload many images at once, with duplicate detection and instant thumbnails
- Metadata generated by Google Gemini (title, keywords, Adobe Stock category, Shutterstock categories, illustration flag)
- **Exactly 50 keywords** per image; the Adobe Stock CSV uses the first 49, the Shutterstock CSV uses all 50
- **API Key rotation:** add several keys and the tool switches to the next key every 3 images. If a key hits a limit or fails, it fails over to another key automatically
- 60-second request timeout, automatic retries, and a **Regenerate** button for failed images
- Per-image status indicator: pending (yellow), processing (blue), done (green), failed (red)
- Edit any title, keywords or category before exporting
- Real-time **log panel** (copyable) that records everything: uploads, keys, requests, errors and exports
- Light and dark mode, responsive layout for desktop and mobile

## Getting started

1. Get a free API key from [Google AI Studio](https://aistudio.google.com/).
2. Open `index.html` in a browser, or host the repository with GitHub Pages.
3. Click **API Key**, paste a key and press **Enter** (or **Add**). Choose a model, then click **Done**.
4. Click **Upload** and select your images.
5. Click **Generate**. Review the results with **Edit**.
6. Click **Download** and choose **Adobe Stock** or **Shutterstock**.

Keep `index.html`, `style.css` and `app.js` in the same folder.

## Using multiple API keys

Gemini free-tier limits are applied **per Google Cloud project**, not per key. Several keys only help if they belong to **different projects** (for example, keys from different Google accounts). Check Google's terms before creating many projects to work around quotas.

## Uploading the CSV files

- **Adobe Stock:** columns are `Filename, Title, Keywords, Category, Releases`. Filenames can be at most 30 characters. The CSV has no content-type column, so set Photo or Illustration in the Contributor Portal.
- **Shutterstock:** columns are `Filename, Description, Keywords, Categories, Illustration, Mature Content, Editorial`. **Upload your images first, then the CSV**, otherwise Shutterstock reports missing assets.

## Privacy

- API keys are stored only in your browser (`localStorage`) and are never written to the log in full.
- Images are resized to a maximum of 1024 px and sent straight to the Gemini API. On the free tier, Google may use submitted content to improve its products, so consider a paid tier for unreleased or sensitive work.

## Limitations

- AI output can be wrong or generic. Always review titles, keywords and categories, and check them against each platform's current rules (trademarks, people and property releases, AI-generated content disclosure).
- The `Releases`, `Mature Content` and `Editorial` fields are exported as empty or `No`.
- Available Gemini models and free-tier limits change over time.
